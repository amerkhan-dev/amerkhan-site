  • Python
  • Crash recovery
  • Durable execution
  • Evidence adjudication

  • Built the evidence-adjudication layer: five modules and 65 assertions resolving escalated cases from out-of-band records. Zero false resolutions in 200 graded cases, against 13 for an unvalidated control, closing 90 previously unrecoverable halts.
  • Measured the assumption: ran the project's first live model-divergence experiment, with 250+ API calls across five experimental blocks. Observed no decision divergence in those settings and published the null result.
