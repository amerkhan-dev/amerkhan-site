Evidence, before action.

My scope included the core architecture, evidence-adjudication layer, evaluation, crash-path fixes, and the team's pitch.

Read the findings ↗
  • Built the evidence-adjudication layer: five modules and 65 assertions resolving escalated cases from out-of-band records. Zero false resolutions in 200 graded cases, against 13 for an unvalidated control, closing 90 previously unrecoverable halts.
  • Measured the assumption: ran the project's first live model-divergence experiment, with 250+ API calls across five experimental blocks. Observed no decision divergence in those settings and published the null result.
  • Found and fixed two high-severity defects: torn-journal-tail data loss and an interrupted-allocation KeyError after money had moved in the simulation. Thirteen of 15 new regression tests failed on unfixed main.
  • Re-verified the headline result: zero contract violations in 240 anchored-runtime trials, within a 960-trial comparison using real process kills.
