Belay

Crash recovery for AI agents that move money.

2nd in Agentic AI, East v. West Hackathon 2026. Team of three. I led the architecture, build and pitch.

An agent calls a payment API and the process dies before the acknowledgement comes back. Did the $50 leave or not? Retry and you can pay twice. Replay the workflow and the model can decide differently the second time.

Belay writes down each action's identity before the model is asked anything. Recovery reads that journal and checks what happened, and when the evidence can't say, it stops for a person.

Source code Recorded walkthrough Findings

  • Built the evidence-adjudication layer. When the anchored runtime halts, a person gets handed a hex string. This layer works those halts from out-of-band records: five modules and 65 assertions. The model may only point at evidence. Pointers are fetched deterministically and its verdict is checked against what was actually fetched, so a hallucinated pointer resolves to nothing and an unsupported verdict becomes an abstention. Zero false resolutions in 200 graded cases, against 13 for the unvalidated control, closing 90 previously unrecoverable halts.
  • Measured the assumption. Belay rests on the idea that a model can change its mind on replay, so I ran the project's first live model-divergence experiment: 250+ API calls across five experimental blocks, identical stateless requests, no cache and no fixed seed. Observed no decision divergence in those settings and published the null result as a bound, not as zero: at most 11.3% pairwise disagreement at 95% confidence for each 50-response block.
  • Found and fixed two high-severity defects. A torn journal tail that could hide later durable records, and an interrupted anchor allocation that raised a KeyError after money had moved in the simulation. Thirteen of 15 new regression tests failed on unfixed main.
  • Re-verified the headline result. Zero contract violations in 240 anchored-runtime trials, within a 960-trial comparison using real process kills.

Results from controlled, synthetic-payment experiments. When evidence cannot establish what happened, Belay stops for review.

Poker Equity & EV Simulator

Built for coursework, then extended into the probability sandbox the UConn FinTech Club teaches from.
